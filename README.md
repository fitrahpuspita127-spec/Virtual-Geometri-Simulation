# Virtual-Geometri-Simulation
Media ini memuat virtual lab mengenai model molekul yang ditampilkan secara 3D, yang dirancang menggunakan coding yang dibuat melalui HTML, CSS, Java Script. Disusun oleh Nabilla Agatha dan Fitrah Puspita, yang merupakan mahasiswa Pendidikan Kimia angkatan 2025 Universitas Sriwijaya, untuk memenuhi tugas mata kuliah Media Pembelajaran Kimia
